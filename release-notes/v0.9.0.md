# Project Browser 0.9.0

Docked DevTools, real extension installs from the Chrome Web Store, a Chrome-style Memory Saver, and five new
Chrome and Brave features.

## DevTools inside the window

- **F12** (also Ctrl+Shift+I, Ctrl+Shift+J, Ctrl+Shift+C, and "Inspect" in the right-click menu) opens DevTools
  **docked below the page**, like Chrome, instead of as a separate window. F12 again closes it.
- The bar above DevTools moves it to the **bottom**, the **right**, or **its own window**, and closes it. Drag the bar
  (or the grip, when docked on the right) to resize it.
- Every tab has its own DevTools, shown only while that tab is in front. Tabs with DevTools open never go to sleep.
- DevTools uses memory only while it is open; closing it frees it.
- Settings > Extensions > Developer tools chooses where it opens.

## Extensions

- **Install from the Chrome Web Store with one click.** Open an extension's store page and press **Add to Project
  Browser** in the bar above the page (the store's own button only works in Chrome). The browser downloads the same
  package Chrome would, straight from Google, and installs it.
- **Install a .crx file** (Settings > Extensions > Install .crx…).
- **Extensions button** in the toolbar: lists your extensions, opens their **pop-ups** under the toolbar (as in Chrome),
  opens their **options** pages, and **pins** extension icons to the toolbar.
- Removing an extension also deletes the files the browser unpacked for it.
- Pages are still rendered by Microsoft Edge WebView2, so a few extension APIs that need Chrome itself (for example
  side panels) are not available; most extensions work.

## Tabs

- **Pulling a tab out of the window** now shows a card that follows the mouse and says what letting go will do: open the
  tab in a new window, move it into the window under the pointer, or move the whole window.

## Memory

- **Memory Saver** (Settings > Performance): Off, Balanced or Maximum, like Chrome. Maximum puts background tabs to
  sleep after 3 minutes and unloads sleeping tabs when the browser goes over 1.5 GB.
- New installs put background tabs to sleep after 15 minutes instead of 30.

## Five new Chrome and Brave features

1. **Reading List** (Chrome): save pages to read later. Sidebar > Reading List, "Add this page", and "Add link to
   Reading List" when you right-click a link. Unread and read pages are listed separately.
2. **Global Privacy Control** (Brave): on by default. Every site is told you do not want your data sold or shared
   (`Sec-GPC: 1`, `navigator.globalPrivacyControl`). Settings > Privacy switches it off.
3. **Strong password generator** (Chrome): right-click a password field > **Insert a strong password**. 20 random
   characters from Windows' secure random generator, put into the field and copied.
4. **Cookies and site data** (Chrome): the site information panel (the icon left of the address) shows how many cookies
   the site keeps, lists them, and **deletes all of the site's data** with one button.
5. **Memory Saver** (Chrome), above.

## Tested

- DevTools in the real app, with real keyboard input (new `scripts/devtools-probe.ps1`, also run by CI): F12 docks
  DevTools inside the window in about 0.3 s, painted, with no separate window left on screen; F12 again closes it.
- Tab tear-off in the real app with real mouse drags (`scripts/ui-probe.ps1`): a new window appears, its page is painted
  and takes input.
- Global Privacy Control in the real app against a local test page: the header arrived as `1` and the page saw `true`.
- Chrome Web Store download path with a real package (uBlock Origin Lite): CRX3 parsed, unpacked, manifest and pop-up
  read. The full click on "Add to Project Browser" in a window has not been tried yet.
- Not yet tried in a window: extension pop-ups, the cookies list and "Delete all data for this site", Reading List.
- Rust unit tests (including new ones for docking layout, store ids, CRX parsing, manifests and passwords), Clippy with
  warnings as errors, and the frontend tests all pass.

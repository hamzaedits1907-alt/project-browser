**Project Browser 0.1.2** is a small follow-up to 0.1.1.

- Fixed: a tab with an untouched drop-down list (a `<select>` with no preselected option) was wrongly treated as holding typed-in text, so it could never be unloaded to free memory.
- Fixed: when WebView2 declined to put a tab to sleep, the browser asked again every 5 seconds and wrote a log line each time. It now waits a minute between attempts.
- Added: update checks and installs are written to the log file, so you can see what the updater did.
- Measured: the repeatable memory benchmark and its first results are in the project's documentation (`docs/BENCHMARK.md`).

You can install this one from inside the app: Settings → About → Check now.

**Project Browser 0.1.1** fixes the crash on startup in 0.1.0 and adds in-app updates.

- Fixed: the app crashed a few seconds after opening on some PCs (WebView2 runtime 154). The cause was in the memory sampler that fills the new-tab RAM figure; it now keeps its objects alive correctly and switches itself off if a runtime ever crashes there again.
- New: Settings → About checks for updates, shows what is new, and installs after you confirm. Updates are verified against a signature before anything is installed.
- New: optional memory limit that puts the least-recently-used background tabs to sleep, protection for pinned tabs and tabs with running downloads, and an unsaved-text check before a tab is unloaded.
- New: a log file (Settings → About shows where) records each startup step, so a problem can be diagnosed.

Install 0.1.1 once by running the installer. Later versions install from inside the app.

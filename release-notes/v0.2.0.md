**Project Browser 0.2.0** — better Chrome migration, a password vault, and NVIDIA-only AI.

**Moving over from Chrome, Edge or Brave**
- History now keeps every visit with its original date, not just the last one.
- Saved addresses and the tabs you had open are imported (open tabs need the other browser closed).
- Saved passwords: export them from your old browser (a CSV), choose the file, and they are stored encrypted for your Windows account. The browser can overwrite and delete the file right after. Nothing is ever read from the old browser's own locked password store.
- A key button in the address bar fills a saved login or address when you click it, on the exact site only, over https only, and never submits the form.
- The result screen reports each kind of data separately: added, already there, failed, and what can't be imported (cookies, payment cards) with the reason.
- Cookies and "stay signed in" sessions are **not** migrated: browsers encrypt them for themselves and sites bind sessions to the browser. Sign in once; your imported password fills the login.

**NVIDIA AI**
- NVIDIA is now the only provider. Enter your NVIDIA API key; it is checked with NVIDIA and stored in Windows Credential Manager.
- Choose a model from a searchable list loaded from NVIDIA. Your choice is remembered; the key never is.
- Test connection, clear messages for a wrong key, no internet, rate limits, retired models and more.
- Image input and tool calling stay off for a model until a real check confirms them.
- Settings from the old multi-provider version are reset; if an old key for another provider is still in Credential Manager, Settings offers to remove it.

**Smaller things**
- Settings has a search box; the main menu has a Passwords and autofill entry.
- Clearer wording and error messages in the import wizard and AI settings.

Not verified by automated tests: the importer against your real profile, the file dialog, and filling on real sites. The checklist is in `docs/VERIFY-WINDOWS.md`.

You can install this one from inside the app: Settings → About → Check now.

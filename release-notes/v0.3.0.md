**Project Browser 0.3.0** — Project Memory, Research, controlled AI actions, and a clearer Chrome migration.

**AI (NVIDIA)**
- **Setup can't get stuck.** The key box works at every stage, the settings page says which stage you're at, and if NVIDIA can't be reached to check a key you can save it anyway and test it later (a key NVIDIA rejects is never saved).
- **Research** (`browser://research`, or the layers button in the assistant): tick open pages and compare them, or put a question to them (Claim Battle). Every quote the model gives is checked against the page it says it came from. Statements without a checkable quote are shown as unverified, never as evidence, and nothing is ever called "proven".
- **Project Memory** (`browser://memory`): notes, summaries and research you chose to keep. Searchable, editable, deletable, local. Nothing is saved on its own.
- **Act**: describe a task, read the plan, untick anything you don't want, then Run. It can only use a fixed list of safe actions (open pages, search bookmarks or memory, read or restyle the current page, save to memory). It cannot run commands, touch files, submit forms or download anything, and a web page can never add a step.
- **Shortcuts in the assistant**: explain or translate your selection, extract data, a summary where every point quotes the page, and a local, reversible page restyle.
- **Cost controls**: a setting for the most page text one request may carry (enforced by the browser's core), cleaner page extraction (menus, footers and form contents left out), Stop that works immediately, and a time and length limit on replies.

**Chrome migration**
- After an import you get a checklist: imported, already imported, not supported (with the reason), needs Chrome closed, needs you, failed. You can repeat just one item.
- *Sign in to Google* opens Google's own sign-in page. Your sessions persist across restarts where websites allow it. Existing Chrome logins still cannot be migrated.
- "Open in private tab" for bookmarks now really opens a private tab.

**Under the hood**
- Update tests now also cover numeric version comparison (0.10.0 > 0.9.0) and bad feed versions.
- The Performance page states exactly what "memory" means.

**Not verified:** nothing here has been run against NVIDIA with a real API key, Google sign-in in this browser has not been observed, and the Chrome importer has not been run on the developer's real profile. The test list is `docs/VERIFY-WINDOWS.md` (section "0.3.0").

Install it from inside the app: Settings → About → Check now.

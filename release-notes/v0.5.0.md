# Project Browser 0.5.0

A new interface from top to bottom, plus tab groups, the browser's own right-click menu, real tab dragging between
windows and element hiding in Project Shield.

## New look ("Vector")

- New visual identity: bevelled shapes, an energy line on the active tab, glow that follows the theme, a new logo.
- Eight themes: Neon Cyan, OLED Black, Violet Pulse, Tactical Green, Crimson, Minimal Dark, Performance (flat, no glow,
  no animation) and Custom (any accent hue). Accent override, corner style (angular / rounded / soft), density, tab style
  (shaped / pills / minimal), vertical tabs, compact title bar.
- Motion system with Subtle / Standard / Expressive intensity; Reduce motion, the Performance theme, Gaming Mode and the
  Windows setting switch animation off. Optional quiet interface sounds (off by default).
- Sidebar with panels docked next to the page (Bookmarks, History, Downloads, Project Shield), the AI assistant, pages,
  pinned sites, Gaming Mode and profile. Reorder or hide entries; show labels; hide the sidebar.
- Customizable toolbar; downloads button with a live progress ring; address bar with a search-engine selector and
  Alt+Enter for a new tab.
- New Tab page: clock, shortcuts you can add and remove, widgets (continue browsing, recently closed, bookmarks,
  downloads, measured memory/CPU, Gaming Mode, Ask AI), five backgrounds, minimal layout.
- Redesigned Settings with grouped categories and a theme gallery.

## Tabs and windows

- Tab groups: name, colour, collapse, add/remove tabs, ungroup, close group; kept across restarts.
- Drag a tab to reorder (neighbours make room), pull it out to make a new window at the pointer, or drop it onto another
  window's tab strip. The page keeps running (its WebView2 view is re-parented). Escape cancels. "Move tab to…" in the
  tab menu still works.
- Close tabs to the right; open links and bookmarks in a new or private window.

## Right-click menus

- WebView2's Microsoft-styled menu is replaced by Project Browser's own for pages, links, images, selections, text
  fields, audio and video. Copy, paste, save image, picture in picture and the other built-in commands are executed by
  WebView2 itself; nothing is simulated with page scripts. AI and Project Memory entries never appear in private tabs.
- Right-click the toolbar, sidebar or title bar to customize the layout or switch theme.

## Project Shield

- Element hiding: site-specific hiding rules from the filter lists are applied (generic and procedural rules are counted
  and not applied, for speed and safety).

## Honesty notes

- Interface checked with typecheck, lint, 360+ unit/contract tests and screenshots of a mock core. The native parts
  (context menu, drag between windows, element hiding) are compiled and unit-tested in CI and exercised by a CI probe
  with real mouse input; see docs/VERIFY-WINDOWS.md for what still needs a person.

# Project Browser 0.7.0

The biggest update so far: split view, a Command Center, a reader that reads aloud, SponsorSkip for YouTube, Focus Mode
with Screen Time, Link Cleaner, full-page screenshots, two new themes, and a fix for tabs dragged into a new window.

## New

- **Split view.** Two tabs side by side in one window (Ctrl+Shift+E, the columns button, or a tab's right-click menu
  > "Open in split view"). Drag the divider to resize, double-click it to even it out. Clicking into a half makes it the
  active tab, so the address bar and shortcuts follow you.
- **Command Center (Ctrl+K).** One box for everything: switch to an open tab, run any of 70+ browser commands, open
  bookmarks and history, jump to a settings page, change the theme, do sums and unit conversions. `>` shows only
  commands, `@` only tabs. Ctrl+Shift+A opens it too.
- **Reader view and Listen (F9).** The article without the clutter, in the browser's own typography: text size,
  serif or sans, paper / sepia / night, narrow or wide column. **Listen** reads the article aloud with the voices of
  Windows, highlighting the paragraph being read; double-click any paragraph to start there.
- **SponsorSkip for YouTube.** Sponsor reads, self-promotion and "like and subscribe" reminders inside videos are
  skipped automatically, using the SponsorBlock community database, with a "Skipped · Undo" notice. Only the first four
  characters of a hash of the video id are sent, so the service cannot tell which video you watch. Off in private
  tabs. Switch: Settings > Project Shield.
- **Focus Mode and Screen Time.** Start a 15/25/50/90-minute focus session and distracting sites (your list) show the
  Focus page instead. Set daily limits per site. browser://focus shows today's time per site and the last 7 days. All
  of it stays on this computer.
- **Link Cleaner.** Tracking codes (`fbclid`, `gclid`, `utm_…` and about 50 others) are removed from addresses before a
  page loads. "Copy clean link" is in the Command Center and the Share dialog. Switch: Settings > Privacy.
- **Screenshots (Ctrl+Shift+S).** What you see or the whole page, previewed, then copied or saved to Downloads as PNG.
- **Address bar answers.** `12*7`, `sqrt(2)`, `10 km in miles`, `72 f to c`, `2 gb in mb` are answered as you type
  (Ctrl+Enter copies). Bangs: `!yt lofi`, `!w rust`, `!gh tauri`, `!r`, `!a`, `!so`, `!mdn` and 15 more.
- **Side panels:** Notes (one per site plus a scratchpad), Media hub (play/pause, speed 0.75–3×, ±10 s, loop and
  picture-in-picture for the page in front, and every tab making sound), Focus & Screen Time.
- **Workspaces.** Save the window's tabs under a name and bring them back later as a tab group. Stored as bookmarks
  (Other bookmarks > Workspaces), so they are kept like any bookmark.
- **Share.** A QR code of the page for your phone, plus copy link / clean link / Markdown link.
- **Per-site memory.** Zoom is remembered per site, as in Chrome. "Dark pages" turns a light site dark and keeps it so.
- **Tab tidy-up.** Close duplicate tabs, sort tabs by site, group tabs by site (tab right-click menu, Command Center).
- **Themes:** **Studio** (calm graphite, soft blue, no glow) and **Daylight**, the first light theme.
- **Shortcuts:** F1 shows them all. New: Ctrl+K, Ctrl+Shift+A, Ctrl+Shift+E, Ctrl+Shift+S, F9.
- New optional toolbar buttons (Customize toolbar): split view, reader, screenshot, Command Center. New optional
  sidebar entries: Notes, Media hub, Focus.

## Fixed

- **A tab dragged out into a new window showed a black page.** The moved page is now re-hosted in its new window
  (WebView2 is told its new parent, the view is raised above the window's interface and redrawn).
- The native UI test in CI now judges what happened by window handles and pixels instead of log lines, so it can
  tell a black page from a painted one, and it checks that the moved page still takes input.

## Engine

Pages are still rendered by **Microsoft Edge WebView2**. This release adds the first step toward a bundled Chromium
engine: a CI prototype that builds CEF (Chromium Embedded Framework) on Windows, renders real sites in it and reports
what the bundled engine supports. The findings, and what is still missing before Project Browser can ship its own
engine, are in `docs/ENGINE.md`.

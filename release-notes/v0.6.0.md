# Project Browser 0.6.0

Project Browser can now be your Windows default browser, and it can run browser extensions.

## Default browser

- **Windows now lists Project Browser as a browser.** The installer registers it with Windows, so it appears in
  Settings > Apps > Default apps and in "Open with" for web pages and `.html` files. Earlier versions never did this,
  which is why Windows did not offer Project Browser as a choice.
- **Links from other apps open in a new tab.** If the browser is already running, the link goes to the open window
  instead of starting a second copy. Links with query strings, Unicode and local `.html` files (including paths with
  spaces) are handled. A link handed over by another program can never run script (`javascript:` and `data:` links are
  refused).
- **Settings > General > Default browser** shows whether Project Browser is your default and has a button that opens
  the right page of Windows Settings. Windows stays in charge: Project Browser never changes your default by itself.

To make it your default after installing: Settings > General > Default browser > **Open Windows settings**, then choose
Project Browser for HTTP and HTTPS (or click "Set default").

## Extensions

- **Settings > Extensions** loads unpacked Chromium extensions (pick the extension's `manifest.json`), lists them, and
  switches them on, off or removes them. They stay installed after a restart and run in every normal tab, but never in
  private tabs.
- Extensions are run by Microsoft Edge WebView2, so there is **no Chrome Web Store**, `.crx` files cannot be installed,
  and there is no extension toolbar, so extension pop-up windows cannot be opened. Extensions that work through content
  scripts and blocking rules (for example dark-mode or content-blocking extensions) are the ones that are useful here.

## Fixes

- **Escape now closes the right-click menu**, and the menu's arrow keys work. Keyboard focus used to stay with the
  hidden page while the menu was open.

## What did not change

- **Pages are still rendered by Microsoft Edge WebView2.** Moving to a bundled Chromium engine (CEF) was investigated
  for this release and not shipped: every browser feature is built on WebView2's API, Tauri has no production CEF
  runtime, the installer would grow from about 4 MB to about 100 MB, and the change could not be tested safely here.
  `docs/ENGINE.md` explains this in detail.

## Checked so far

- In CI, on a Windows runner, the real installer is installed, then every registry value is checked. Links are opened
  through the registered command (first start, a second link sent to the running browser, a local `.html` file), then
  the browser is uninstalled and the registration is confirmed gone. All 18 checks passed.
- **Not checked by anyone yet:** picking Project Browser in Windows Settings, using extensions in a real window, and the
  Escape fix. Please report problems with any of them.
- The YouTube ad blocking from 0.5.1 still needs real-world testing.

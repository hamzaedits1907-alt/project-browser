# Project Browser 1.0.0

Bugs you reported, fixed, and twenty big new features, plus an AI assistant that can do far more.

## Fixed

- **Typing in the address bar works again.** Every key you typed used to hide the page behind a still picture and move
  keyboard focus, so the address bar reset itself and threw away what you typed. The suggestion list is now drawn in
  its own small window over the live page, and focus never moves.
- **The page no longer freezes when you open the ⋮ menu.** The main menu opens in its own window below its button;
  the page keeps running (videos keep playing). A second click on ⋮ closes it.
- **No more frozen page under any popup.** Site information, Shield, extensions, downloads and every other popup cut a
  hole into the page exactly where they are drawn; the page stays visible and running around them. Clicking the page
  closes the popup.
- **Full-screen videos fill the whole screen.** A maximized window used to keep a strip at the bottom (the taskbar's
  height). Full screen is now applied by Windows directly, and the window is maximized again afterwards.
- Test runs with their own data folder keep single-instance behaviour again (the registration and download checks in
  the build pipeline need it).

## Twenty new features

1. **No frozen popups**, above.
2. **HTTPS-Only Mode** (Settings > Privacy): every site over a secure connection, with a warning page before an
   insecure one. Sites on your own network are left alone.
3. **Fingerprinting protection** (on): canvas, audio and WebGL read-backs vary per site and session, like Brave, so
   they can't identify you. Pages look and sound the same.
4. **Cookie-banner blocker** (on): consent banners are answered with "Reject all" / "Only necessary" for you.
5. **Mouse gestures** (on): hold the right button and draw. Left = back, right = forward, up-down = reload, down-right =
   close tab, down-left = reopen closed tab, up = new tab, up-left / up-right = previous / next tab. A line and the
   action's name follow the pointer.
6. **Site settings** in the site information panel: block JavaScript or keep the sound off per site.
7. **Tab hover cards** with a small picture of the page, its site, and whether it sleeps, plays sound or uses a lot of
   memory. Pictures are a few kilobytes each.
8. **Highlighter**: select text, right-click, Highlight. Highlights come back every time you open the page; the
   Highlights panel lists them all. "Copy link to highlight" works on every page.
9. **Copy text from image**: right-click a picture. Windows' own text recognition reads it, on this computer.
10. **Search inside visited pages**: History finds pages by what they said, not just their titles (kept locally,
    normal tabs only; switch it off in Settings > General and it is deleted).
11. **Element zapper**: "Hide an element on this page…" (Command Center or site information panel). Click anything
    annoying; it stays hidden on that site.
12. **Password Checkup** (Settings > Passwords): weak, reused and leaked passwords. Only 5 characters of each
    password's hash are ever sent (Have I Been Pwned's range check).
13. **Automatic picture-in-picture**: a playing video keeps playing in a small window when you switch tabs, and comes
    back when you return.
14. **Do Not Track** and **delete cookies and site data when the browser closes** (Settings > Privacy).
15. **Tab cleanup** (Command Center): duplicate tabs and tabs unused for 3 to 30 days, closed together after a check.
16. **Address-bar scopes**: type `@tabs`, `@bookmarks` or `@history` and a space to search only that.
17. **Video speed keys** on every video: S slower, D faster, R normal, Z / X jump 10 seconds.
18. **Media on this page** panel: every picture, video and sound on the page, saved with one click (or all at once).
19. **Your own keyboard shortcuts** (Settings > Keyboard shortcuts).
20. **Energy Saver** (Settings > Performance): on battery, background tabs sleep after 5 minutes and the browser's
    animations stop. A green leaf shows when it is on.

## AI assistant

- **33 tools instead of 9** in "Do it for me" (AI panel > Actions): search, switch, close and group tabs; search
  history (also inside pages); search the web; bookmark, Reading List, highlight, find, zoom, dark mode, screenshots,
  Reader view, mute; Focus sessions, notes and panels; list page media; answer questions about the page; translate it;
  write text (emails, replies, lists); copy results.
- Every plan is still shown first and runs only when you press Run; you can untick steps. Pinned tabs and the tab you
  are on are never closed; private tabs are never read.
- **8 new one-click requests** in the chat: TL;DR, Key takeaways, Explain simply, Pros and cons, Action items, Quiz me,
  Fact check, Reply draft.

## About "WebView2 Manager" in Task Manager

Windows' Task Manager names the page processes of browsers built on WebView2 "WebView2 Manager". Windows only shows
them under the app's own name for apps installed as a Windows package (MSIX). It cannot be changed by a setting in the
browser.

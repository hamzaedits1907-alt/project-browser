**Project Browser 0.4.0** — NVIDIA setup fix, working downloads, real extra windows, Project Shield, popups, and an honest Project Tunnel.

**Fixes you asked for**
- **NVIDIA key setup.** Saving the key no longer depends on a model answering. Before, *Connect* sent a chat request first and kept the key only if it succeeded, so a retired or unavailable model showed "Model not available" and the key was never stored. Now **Save key** only stores it (offline, no model selected, retired model, catalog down: all fine), and **Test connection** is a separate button with its own result, including a new "key not confirmed yet" state when no model answered.
- **Downloads.** Your log showed two downloads that started in a fresh tab which was then closed: WebView2 ties a download to its tab's webview, so closing it killed the transfer and left a row stuck on "in progress" that could not be cancelled. The tab's webview now stays alive until its downloads end, tabs opened only to start a download close themselves, a dead transfer is shown as interrupted, and every download is logged with the reason when it fails.
- **Crash when typing non-English text** in the address bar (ö, ç …) is fixed (it appeared three times in your log).

**New**
- **Windows.** Ctrl+N opens a new window, Ctrl+Shift+N a private window (private tabs only, never saved), Ctrl+Shift+W closes a window; the last window closes the browser. Windows restore after a restart with their positions; Ctrl+Shift+T brings back a closed window. Move a tab to another or a new window from its menu (the page keeps running), or drag it out.
- **Project Shield.** Blocks ad and tracker requests before they are sent, using EasyList and EasyPrivacy plus a built-in starter set; per-site switch, your own rules and exceptions, counts per page. See `docs/SHIELD.md` for exactly what it does and doesn't do.
- **Pop-ups.** Pop-ups no click asked for are blocked with a bar to open or always allow; sign-in pop-ups a click opens work and share your profile; a setting opens new-window requests as tabs or windows.
- **Project Tunnel.** Send this browser's traffic through a proxy you supply (HTTP or SOCKS5). The status says "Restart needed" until it is really applied, and it is not a system-wide VPN. See `docs/TUNNEL.md`.
- `docs/CHROME-PARITY.md` lists what Chrome has that this browser does and doesn't, feature by feature.

**Not verified:** none of this has been seen in a real window or against real sites. Native behaviour (windows, popups, blocking, downloads, the proxy) is built from the WebView2 APIs and compiled in CI, and its logic is unit-tested, but the manual list in `docs/VERIFY-WINDOWS.md` (section "0.4.0") has not been run. Speed was not measured; no benchmark numbers are claimed.

# Project Browser 0.5.1

A small fix release.

## Fixes

- **Right-click menu opens faster.** Before the menu could appear, the browser had to take a screenshot of the page and
  pass it to the interface as a large block of text. The screenshot now starts at the moment of the right-click and is
  passed as an image file, which is much quicker. The address bar's suggestion list uses the same path and benefits too.
- **Project Shield blocks YouTube ads.** YouTube serves its ads from its own servers, in the same responses as the
  videos, so blocking by web address could not stop them. Shield now runs a small script on YouTube pages (the same
  approach uBlock Origin takes) that removes the ad schedule from the video player's data, hides ad slots on the pages
  and, if an ad still starts, jumps to its end and presses Skip. YouTube's ad-tracking requests are also blocked. It is
  active only while Shield is on for YouTube.

## Known limitations

- The YouTube ad script has not yet been tested by a person on the real site. YouTube changes how it delivers ads and
  detects ad blockers often, so this will likely need maintenance; please report ads that still play.
- Ads removed on YouTube are not yet counted in Shield's blocked counter.
- Both fixes passed the automated Windows build and tests; neither has been confirmed on a user's PC yet.
